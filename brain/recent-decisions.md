# Recent decisions

- The initial GOD AI OS dashboard is a scaffold; unimplemented areas are labeled
  rather than simulated.
- The existing in-memory orchestration prototype remains available and is not
  replaced by this UI.
- The hierarchy cardinality difference between the design and prototype remains
  unresolved; see the design brief before persisting or expanding the hierarchy.
- CI validates Python tests and builds a wheel artifact; it does not publish or
  deploy the application.
