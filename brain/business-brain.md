# Project context

GOD AI OS is intended to be a human-governed, hierarchical multi-agent
operating system. The repository currently contains a small in-memory
orchestration prototype and a local dashboard scaffold.

The authoritative design brief is [GOD AI OS: Foundational Design](../docs/GOD_AI_OS_DESIGN.md).
Current modules marked "Not implemented" are navigation and design placeholders,
not delivered capabilities.
