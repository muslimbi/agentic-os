# Shared brain

This directory is a documentation scaffold for shared project context. Files
here are not yet loaded automatically, synchronized between agents, or stored in
a database. Treat entries as project notes, not verified external facts.

- `constitution.md` records the intended human-governance principles.
- `identity.md` describes the intended product identity.
- `business-brain.md` records current project context.
- `memory.md`, `recent-decisions.md`, and `active-projects.md` are starter notes.
- `journal/` is reserved for dated entries.

The FTS5 search module is not implemented. Do not put credentials, personal
data, or other secrets in this directory.
